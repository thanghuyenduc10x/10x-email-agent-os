# 10X Agent Publishing OS — V1 Spec

## Architecture
10X LifeOS → Second Brain → 10X Studio → Agent Publishing OS → Public Agent → Impact → Second Brain.

## Problem Definition — LOCKED
Sau khi một vấn đề được giải quyết cùng AI, tri thức và tài sản thường phân tán trong conversation, Markdown, code, instruction và website. Người tạo hiểu vì có context; học viên không có context. Cần một quy trình biến một solved problem thành một tài sản trực quan, public và có thể tái triển khai từ một URL duy nhất.

### Problem Statement
Làm thế nào để một vấn đề đã được giải quyết cùng AI được đóng gói thành một tài sản public, trực quan và có thể triển khai lại, để người chưa có context chỉ cần nhận một URL là hiểu Problem → Destination → Roadmap → How-to → Test và biết cách bắt đầu xây hệ thống tương tự?

## Solution Spec V1 — LOCKED
Golden Case: 10X Email Agent.

Pipeline: Solved Problem → Canonical Source → Agent Manifest → Website → GitHub → Publish → Branded URL.

Command cấp cao: `Public Agent`.

Website grammar bắt buộc:
1. Problem
2. Destination
3. System
4. Roadmap
5. Quick Start
6. Test & Definition of Done
7. Evolution

## Definition of Done V1
- Canonical Source tồn tại.
- Agent Manifest tồn tại và hợp lệ.
- Website V1 render được trên desktop/mobile.
- Source được version-control trên GitHub.
- Website có URL online và mục tiêu branded URL `email-agent.10x-lifeos.com`.
- Người mới có thể hiểu Problem → Destination → Roadmap trong ≤3 phút.
- Người mới biết next action trong ≤5 phút.
- Workflow `Public Agent` được định nghĩa và tái sử dụng được.
